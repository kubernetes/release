# krel build type

Build type URI: `https://git.k8s.io/release/docs/krel/buildtypes/v1`

This build type describes a Kubernetes release process run performed by
[krel](/docs/krel), such as `krel stage`. The provenance attestations
generated by these runs follow the
[SLSA provenance v1](https://slsa.dev/provenance/v1) predicate and use this
URI in the `buildDefinition.buildType` field.

## Build definition

:warning: Note that this build definition will grow. We will keep the v1 version
tag for now but we will probably do additive, non-breaking changes as we perfect
the attestation. This directory will also hold the verification rules for the
buildType for the upcoming SLSA verifier scheduled to be released on Q3 2026.

### External parameters

The externally controlled inputs of the run. Their schema is the
`ExternalParameters` message defined in [`buildtype.proto`](buildtype.proto),
serialized with the protobuf JSON mapping. The Go code implementing it
is generated into [`pkg/anago/buildtypes/v1`](/pkg/anago/buildtypes/v1)
(run `make protos` after changing the definitions):

| Field           | Description                                                              |
|-----------------|--------------------------------------------------------------------------|
| `releaseType`   | Type of release to build: `alpha`, `beta`, `rc` or `official`.           |
| `releaseBranch` | Kubernetes branch the release is built from: `master` or `release-X.Y`.  |
| `buildVersion`  | Build version to release, in the form `vX.Y.Z-[alpha\|beta\|rc].N.C+SHA`. |
| `nomock`        | Whether the run stages the artifacts to the production locations.        |
| `entryPoint`    | Cloud Build configuration the run was submitted with.                    |

### Internal parameters

None.

### Resolved dependencies

The Kubernetes source repository the artifacts were built from, identified
by its `git+https` URI and the digest of the commit checked out for the
build.

## Run details

- `builder.id`: `https://git.k8s.io/release/docs/krel`
- `metadata.invocationId`: the Cloud Build build ID of the run.
- `metadata.startedOn` / `metadata.finishedOn`: start of the krel process
  and completion of the artifact staging.

## Example

```json
{
  "buildDefinition": {
    "buildType": "https://git.k8s.io/release/docs/krel/buildtypes/v1",
    "externalParameters": {
      "releaseType": "alpha",
      "releaseBranch": "master",
      "buildVersion": "v1.36.0-alpha.1.10+abcdef0123456",
      "nomock": true,
      "entryPoint": "https://git.k8s.io/release/gcb/stage/cloudbuild.yaml"
    },
    "internalParameters": {},
    "resolvedDependencies": [
      {
        "uri": "git+https://github.com/kubernetes/kubernetes",
        "digest": {
          "gitCommit": "abcdef0123456789abcdef0123456789abcdef01",
          "sha1": "abcdef0123456789abcdef0123456789abcdef01"
        }
      }
    ]
  },
  "runDetails": {
    "builder": {
      "id": "https://git.k8s.io/release/docs/krel"
    },
    "metadata": {
      "invocationId": "0b7a5c7e-5b1a-4c2a-9a1e-7d3f1c2b4e5a",
      "startedOn": "2026-08-22T01:02:03Z",
      "finishedOn": "2026-08-22T03:04:05Z"
    }
  }
}
```
